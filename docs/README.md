[PRJ-0387] 프레스타샵(PrestaShop) 애드온 마켓 모듈 판매

오픈소스 쇼핑몰 PrestaShop용 모듈(예: 상품 일괄 수정, 주문 알림)을 만들어 Addons 마켓에서 판매. 근거: PrestaShop 공식 문서와 판매 안내 페이지가 있음(수요·수익은 추정). 무자본 이유: PrestaShop은 무료 오픈소스이며 판매자 등록 조건은 확인 필요. 기존 Shopware 항목과는 플랫폼·마켓이 다름. 출처: https://addons.prestashop.com/en/content/25-how-to-sell-on-prestashop-addons

설계 문서·자료를 이 폴더에 넣습니다.
